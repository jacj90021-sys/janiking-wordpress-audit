# PROJECT.md — Jani-King Website Recreation

## Objective

Recreate https://www.janiking.com/ as a professional, responsive, fully editable
WordPress website.

## Scope

A native WordPress implementation using:

- WordPress (latest stable)
- Astra Free (theme)
- Elementor Free (page builder)
- Free WordPress plugins only where genuinely necessary
- Custom PHP, CSS and JavaScript only when justified
- GitHub for version control

React, Next.js, Vite, standalone TypeScript applications and headless
replacements are prohibited.

## Current Status: TASK 001 — AUDIT ONLY

No implementation has begun. This document, together with TASKS.md,
DESIGN-SYSTEM.md, documentation/SITEMAP.md and documentation/ARCHITECTURE.md,
constitutes the audit and implementation plan. Work is paused pending
approval of these deliverables.

## Constraints

- Repository must remain small and understandable.
- Do not include WordPress core, unnecessary dependencies, uploaded media
  libraries or generated files in Git.
- Do not create a separate source file for every page section.
- Do not create unnecessary React-style component architecture.
- Create only files justified by the actual WordPress implementation.
- Do not assume Elementor Pro functionality is available.

## Deliverables

1. PROJECT.md — objective and scope (this file)
2. TASKS.md — implementation stages and progress
3. DESIGN-SYSTEM.md — observed visual system
4. documentation/SITEMAP.md — pages and URLs
