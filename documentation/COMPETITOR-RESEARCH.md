# documentation/COMPETITOR-RESEARCH.md — ThemeForest Cleaning-Theme Benchmarks

Source: actual ThemeForest product listings, live demos, and official author
documentation (audited 2026-11-10).

## Purpose

Establish the commercial benchmark standard expected of a cleaning-services
WordPress theme sold on ThemeForest. These are NOT copied — they define the
expected level of product completeness, customization, demo quality,
installation experience, documentation, and technical implementation our
original theme must match or exceed.

## Key commercial benchmarks

### Page builder
- Elementor is the dominant builder among newer products (Bixol, CleanMate,
  Clenix, Clengo, Xcleen, Cleaning Services, Cleanu).
- A few still bundle WPBakery/Visual Composer (CleanMate, Clenix, Moppers,
  The Kleaner).
- CleaningEco requires Elementor Pro (not compliant with our "Elementor Free
  only" constraint — noted as a benchmark but not adopted).

### Custom widgets
Benchmarks advertise 20–65+ custom widgets/components. Our product should
provide a focused set of genuinely useful custom Elementor widgets rather than
inflating the count:
- Hero, Services, Industry cards, Icon boxes, Testimonials, Team members,
  Statistics (counters), Pricing, FAQs, Galleries, Call-to-action, Blog grids,
  Project grids, Contact/quotation sections.

### Header/footer
- Bixol: Footer builder + mega menu.
- Clenix: 8 header styles (12+ variations).
- Clengo: GT3 Header Builder.
- Cleanu: Header & Footer Builder via Elementor.
- CleaningEco: Elementor Pro Theme Builder.
- Our product needs a header/footer customization system without Elementor Pro.

### Demo importer
- Every competitor provides one-click demo import.
- Content varies: Bixol (20 demos), CleanMate (24 page templates), Clenix
  (20+ inner pages), Clengo (pre-designed inner pages), The Kleaner
  (services/projects/team/history/pricing/contact/faq pages).
- Critical: import requires explicit user confirmation, must not overwrite
  without warning, assets must be appropriately licensed for redistribution.

### Companion plugins / frameworks
- Redux Framework theme options (Bixol, Clenix, Moppers).
- GT3 Settings Panel (Clengo).
- SlashCreative Core (Moppers).
- Xclean Theme Addons (Xcleen) — companion plugin with CPTs/shortcodes.
- RadiusBooking (Clenix).
- Appointment Booking + ACF Pro (The Kleaner).
- All competitors use a companion plugin or theme-options framework for
  reusable functionality.

### Premium plugin bundling (Envato constraint)
- Elementor Pro, Slider Revolution, ACF Pro, WPBakery, Booked Appointment are
  commonly advertised as "included" or "save $XX".
- Envato does NOT allow premium third-party plugins to be bundled without
  written permission. Our product must use free plugins only and prompt users
  to install free alternatives from wordpress.org via TGM Plugin Activation.

### WooCommerce
- Most competitors advertise WooCommerce compatibility with a shop page.
- Full shopping workflow should be tested before claiming compatibility.

### Gutenberg
- CleanMate, Clenix, Clengo, The Kleaner, CleaningEco: Gutenberg Optimized =
  Yes.
- Bixol, Moppers, Xcleen, Cleaning Services, Cleanu: Gutenberg Optimized =
  No.
- Our theme must support Gutenberg (block editor) compatibility per Envato.

### Pricing & sales range
- Price range: $39–$90; most cluster at $49–$59.
- Sales range: 267 – 3,856. Bixol is the market leader at 2,298 sales.
- Last updates cluster around 2026 Q3, indicating active maintenance.

### Documentation & support
- All competitors advertise "Well Documented" with online documentation plus
  video guides.
- Support channels: premium support desk, 6–12 months support, support desk.

## What our product must match/exceed

1. Original standalone theme that works without Elementor/companion plugin.
2. Companion plugin for plugin-territory functionality (CPTs, widgets,
   shortcodes, theme-specific features).
3. Custom Elementor Free widgets (focused set, responsive, accessible).
4. Header/footer customization system (no Elementor Pro).
5. Theme options framework (customizer-based).
6. One-click demo importer with explicit consent and overwrite warnings.
7. WooCommerce compatibility (styling + shop pages).
8. WPML/translation readiness + RTL support.
9. Child theme support.
10. Public online documentation + changelog.
11. Envato Theme Check compliance (REQUIRED notices fixed).
12. TGM Plugin Activation for required/recommended free plugins.

## What we deliberately do NOT copy

- Bundling premium plugins (Elementor Pro, ACF Pro, Slider Revolution,
  WPBakery, Booked Appointment) — not permitted by Envato.
- Requiring Elementor Pro (CleaningEco) — violates our "Elementor Free only"
  constraint.
- Inflating widget counts with redundant widgets.
- Distributing protected Jani-King logos/trademarks/photographs — use licensed
  replacement assets.
